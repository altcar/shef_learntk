## Plain text and CSV first

`.csv` is just text with commas, so the standard library handles it. Use the
`csv` module rather than splitting on `","` — it deals with quotes and commas
inside values.

```python
import csv
from pathlib import Path

path = Path("enrolments.csv")

with path.open(newline="", encoding="utf-8") as handle:
    reader = csv.DictReader(handle)      # first row becomes the keys
    for row in reader:
        print(row["name"], row["email"])
```

Writing is symmetrical:

```python
rows = [{"name": "Ada", "email": "ada@example.com"}]

with Path("out.csv").open("w", newline="", encoding="utf-8") as handle:
    writer = csv.DictWriter(handle, fieldnames=["name", "email"])
    writer.writeheader()
    writer.writerows(rows)
```

Two habits worth keeping:

- Always pass `encoding="utf-8"` and `newline=""` for CSV. Without them Excel
  and Windows will eventually mangle something.
- Use `pathlib.Path` instead of string concatenation for paths.

## Why `.xlsx` needs a library

An `.xlsx` file is a zip archive of XML. You *can* unzip it and read the XML,
but please don't. `openpyxl` gives you cells, sheets, formulas and styling.

```python
from openpyxl import load_workbook

workbook = load_workbook("grades.xlsx", data_only=True)
sheet = workbook.active
print(sheet.title, sheet.max_row, sheet.max_column)
```

`data_only=True` returns the **last value Excel calculated** for formula cells
instead of the formula string. It only works if the file has been opened and
saved by Excel at least once; a file generated by a script has no cached values.

## Reading a sheet into Python

The most useful pattern: turn the used range into a list of dictionaries, keyed
by the header row.

```python
def read_sheet(path: str, sheet_name: str | None = None) -> list[dict]:
    workbook = load_workbook(path, data_only=True)
    sheet = workbook[sheet_name] if sheet_name else workbook.active

    rows = list(sheet.iter_rows(values_only=True))
    if not rows:
        return []

    headers = [str(value).strip() if value is not None else "" for value in rows[0]]
    records = []
    for row in rows[1:]:
        if all(value is None for value in row):
            continue                      # skip blank spacer rows
        records.append(dict(zip(headers, row)))
    return records
```

```python
students = read_sheet("grades.xlsx", "Cohort A")
for student in students[:3]:
    print(student["Name"], student["Score"])
```

Row and column numbers in openpyxl are **1-based**, unlike everything else in
Python. `sheet.cell(row=1, column=1)` is cell A1.

## Writing a workbook

```python
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill

workbook = Workbook()
summary = workbook.active
summary.title = "Summary"

summary.append(["Student", "Average", "Grade"])          # header row

for student in students:
    scores = [student[f"Week {n}"] for n in range(1, 8)]
    average = sum(scores) / len(scores)
    summary.append([student["Name"], round(average, 1), grade_for(average)])

# Make the header bold and freeze it in place.
for cell in summary[1]:
    cell.font = Font(bold=True)
    cell.fill = PatternFill("solid", start_color="DDDDDD")
summary.freeze_panes = "A2"

summary.column_dimensions["A"].width = 24
summary.column_dimensions["B"].width = 12

workbook.save("summary.xlsx")
```

`append()` adds a whole row; `save()` is what actually writes the file.

## Formulas and formatting

You can write a formula as a string and Excel evaluates it when the file is
opened.

```python
summary["E2"] = "=AVERAGE(B2:D2)"
summary["E2"].number_format = "0.0"
```

:::caution[Do the maths twice]
A formula is only as good as the spreadsheet it lives in. If you need the value
in Python, compute it in Python (`statistics.mean`) and write the result, or
read the file back with `data_only=True` after Excel has saved it.
:::

Conditional colouring:

```python
from openpyxl.formatting.rule import CellIsRule

red = PatternFill("solid", start_color="FFC7CE")
summary.conditional_formatting.add(
    f"B2:B{summary.max_row}",
    CellIsRule(operator="lessThan", formula=["40"], fill=red),
)
```

## Pandas, briefly

When the data is a rectangle, `pandas` is faster to work with than openpyxl and
it is the natural bridge to the next module.

```python
import pandas as pd

frame = pd.read_excel("grades.xlsx", sheet_name="Cohort A")
print(frame.head())
print(frame["Score"].mean())
print(frame.groupby("Stream")["Score"].mean().sort_values(ascending=False))
```

```python
frame.to_excel("summary.xlsx", index=False)
frame.to_csv("summary.csv", index=False)
```

Rule of thumb:

| Task | Use |
| --- | --- |
| Keep a spreadsheet's formatting, write a report | `openpyxl` |
| Filter, group, calculate, reshape | `pandas` |
| Both | `pandas` for the maths, `openpyxl` for the polish |

## Common traps

- **Merged cells** look like one value but occupy many; `iter_rows` returns
  `None` for all but the top-left. Unmerge before processing, or read the anchor.
- **Dates** arrive as `datetime` objects, not strings. Format them with
  `.strftime("%Y-%m-%d")` when writing to CSV.
- **Numbers stored as text** (leading apostrophe) break `sum()`. Clean with
  `float(str(value).strip())` and check for empty strings.
- **The file is open in Excel** on Windows: `save()` raises `PermissionError`
  because Excel holds a lock. Close it first.
- `.xls` is the ancient format; openpyxl cannot read it. Ask for `.xlsx`, or use
  `pandas` with `xlrd` installed.

## Checkpoint project: the gradebook report

Using `grades.xlsx` (or the sample you build yourself):

1. Read the `Cohort A` sheet into a list of dictionaries.
2. Compute each student's average across the weeks, and the cohort average.
3. Write `report.xlsx` with a `Summary` sheet: one row per student, their
